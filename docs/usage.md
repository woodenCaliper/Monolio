# Monolio 操作ガイド

[READMEに戻る](../README.md)

## 貼り付け

ほかのアプリ(Notion・ブラウザのページ・Google ドキュメントなど)からまとめてコピーして貼ると、見出し・段落・箇条書き・番号付き・ToDo・引用・コード・表・
区切り線・トグル・数式を、それぞれのブロックにして貼ります(Notion は入れ子・チェック・色まで)(キャレットのあるブロックの後ろ。空の段落なら置き換え)。1つの段落や文の一部は、
文の中に入ります。Ctrl+Shift+V は書式なし(文字だけ)の貼り付けです。

## リンク

URL(`https://…` や `mailto:…`)だけを貼り付けると、リンクになります(打った URL や書いてある URL は文字のまま)。文字を選んで書式ツールバーのリンクのボタン(🔗)を押すと、
その文字に好きな URL を付けられます(付けたリンクの書き換え・取り外しも同じボタン)。エディタでは Ctrl を押しながらクリックで開き、
保存した HTML ではクリックで別のタブに開きます。行き先は http・https・mailto だけです。

## 改ページ(印刷・PDF)

`/pagebreak`(`/改ページ`)で「改ページ」ブロックを入れると、印刷・PDF でその位置から次の紙になります。
エディタでは点線と「改ページ」の文字で位置が分かります。保存した HTML を画面で見るときは何も表示されません。

## Mermaid の図

`/mermaid`(`/図`)で Mermaid の図のブロックを入れると、[Mermaid](https://mermaid.js.org/) のコードから
流れ図・シーケンス図などを描きます。図は **SVG** で描き、文字も SVG の文字です(画像にはしません)。

- 入れた直後は小さな流れ図の見本と、そのコードが開いています。コードを書き換えると、打ち終わってから描き直します。
- コードの開閉は図の上の「コードを表示/コードを隠す」。図を押してもコードへ入れます。図の下に題名(「図n:」)も付けられます。
- 文法の誤りは図の下に赤い文字で出ます(前に描けた図は薄くして残ります)。
- 保存した HTML には描いた SVG と、畳んだコードが入ります。Mermaid が無くても(ブラウザでそのまま開いても)図が見え、印刷・PDF にも出ます。
- Mermaid 本体(約4MB)は、図のある文書を開いたとき・図を入れたときだけ読み込みます。

## 機能見本

[機能見本(日本語)](https://woodencaliper.github.io/Monolio/sample/monolio-features.html)([英語版](https://woodencaliper.github.io/Monolio/sample/monolio-features.en.html)。ファイルは [docs/sample/](./sample/))は、Monolio の機能をひととおり使った見本の文書です。
ブラウザでそのまま開けるほか、ダウンロードして Monolio の File → Open で開けば編集もできます。
子ページ「図(Mermaid)の全種類」に、Mermaid で描ける図の全種類(35種)の見本があります。

## フォント

表示は **OS・環境の標準フォント**です。アプリはフォントを同梱しません。書体は
「本文 / 明朝 / 等幅」の3枠で、それぞれ環境ごとの標準的な書体に解決されます。

| 枠 | 指定 |
| --- | --- |
| 本文 | `system-ui, -apple-system, "Segoe UI", "Hiragino Sans", "Yu Gothic UI", Meiryo, sans-serif` |
| 明朝 | `"Hiragino Mincho ProN", "Yu Mincho", YuMincho, "MS PMincho", serif` |
| 等幅 | `ui-monospace, SFMono-Regular, Consolas, "Courier New", monospace` |

エディタと保存HTMLは同じ指定を使うので、**同じ環境で開けばエディタと保存HTMLの見た目が一致します**。

### 環境による違い

- **環境をまたぐと字形が変わります**。作った端末と読む端末で書体が違えば、行の折り返しや
  文字の形は変わります（同じ端末で開くかぎりエディタと保存HTMLは一致します）
- **日本語の等幅（桁揃え）は保証されません**。OS標準の等幅フォントは日本語を持たないことが
  多く、日本語部分は本文書体へ落ちて幅が揃いません

字形まで揃えたい文書では、次の「フォントを埋め込む」で自分で書体を添付してください。

### フォントを埋め込む（オプション）

Files メニューの「フォントを埋め込む」から woff2 / woff / ttf / otf を添付すると、その
書体が書体一覧に加わり、本文へ適用できます。**適用した書体だけ**が保存HTMLにファイル
まるごと埋め込まれるので、読む側の環境に関係なく同じ字形になります（使わなくなった
書体は保存時に自動で落ちて、ファイルは軽いままです）。

## Markdown風ショートカット

行頭で `# `（見出し1〜5は `#` の数）、`- ` / `* ` / `+ `（箇条書き）、`1. `（番号付き）、
`> `（引用）、`[] `（チェックボックス）と打つと、そのブロックに変わります。

変換は**区切りのスペースを押した時点**です。`# ` と打った瞬間に空の見出しになり、
続けて打った文字がそのまま見出しの本文になります。記号ごとの違いはありません。
やめたいときは Undo（Ctrl+Z）で「記号+スペース」の段落に戻ります。
日本語入力の変換中のスペース（候補送り）では変換されません。

## 文中のページへのリンク

本文で `@`(全角の `＠` も)に続けて打つと、ページの一覧が出ます(打った語で絞れます)。選ぶと、そのページへのリンクが文の中に入ります。
ページの題名を写し、題名を変えるとついてきます。押すとそのページへ移ります(保存HTMLでも)。

## 見出しの番号と参照

View メニューの「見出しに番号」を入にすると、見出し1〜3（トグル見出しも）に「1」「1.1」「1.1.1」の番号が
**文書全体の通し**（ページをまたいで続く）で付きます。設定は文書ごとに保存され、既定は切です。
番号は見出しの文字ではないので、並べ替え・削除・見出しの段の変更で自動で振り直され、検索にも当たりません。
見出し4・5には付きません。上の段を飛ばすと、その段は 0 になります（見出し1の直下の見出し3は「1.0.1」。Word と同じ）。
目次・画面上部の見出しの道筋・保存HTML・印刷にも同じ番号が出ます。

`/参照` の一覧には見出しも出ます。選ぶと「2.1 目的」のような印が入り（番号が切なら名前だけ）、見出しの番号や名前を
変えると印も変わります。押すとその見出しへ移ります（保存HTMLではリンク）。

行の**先頭で Backspace** を押すと前のブロックへ、**末尾で Delete** を押すと次のブロックが
ここへ繋がります（改行を消した、という感覚のとおりの動きです）。繋いだあとの種別は
カーソルのあるブロック側を保ちます。表・コード・グラフ・数式・添付・区切り線のような
構造を持つブロックとは繋がりません（中身が壊れるため、何も起きません）。

``` ``` （バッククォート3つ）はスペースを使わないため、3文字目でコードブロックになります。
`---`、`___`、`***` は区切り線です。コードブロックや数式ブロックの中身はソースとして
扱うので、`# コメント` や `---` と書いてもブロックは変わりません。

## 表とグラフ

`/table` で表、`/chart` でグラフを作れます。

表・グラフ・画像には、左のつまみのメニューの「題名を付ける」で題名を付けられます。題名を付けたものには
「表1:」「図1:」のような**文書全体の通し番号**が自動で付きます(表は上、図は下。並べ替えると振り直されます。ページをまたぐときはページ一覧の並びで数えます)。
本文で `/参照` と打つと題名の付いた表・図の一覧が出て、選ぶと「表1」のような印が入ります。番号が変わると印も
自動で変わり、押すとその表・図へ移ります(保存HTMLではリンク)。

表はセルの結合（縦・横）と分解、行と列の挿入・削除、ヘッダー行・ヘッダー列（最左列の
タイトル）の切り替えに対応します。ヘッダーのセルは背景トーンと太字で本文と区別されます。
ヘッダーと本文の境界をまたぐ結合はできません（またぐ結合がある表をヘッダー化すると、
その結合は自動で解除されます。通知が出て、Undo 1回で丸ごと戻せます）。

行・列は、編集中に出る行の左・列の上の取っ手をドラッグすると入れ替えられます(データベースも同じ)。式の参照はセルについていき、
合計などの範囲は、範囲の中で並べ替えるだけなら変わりません。ヘッダー行・列と、結合したセルを分ける移動はできません。

長い表は、表の下の端のつまみを上下にドラッグすると、見せる高さを決められます。超える分は表の中でスクロールし、見出しの行は
上に残ります。ダブルクリックで全部見せる形に戻ります。保存したHTMLでも同じ高さで見え、印刷・PDF では全行が出ます。

### データベース

表は、表の道具の帯の右端の「データベース」(またはつまみのメニュー)でデータベースにできます。1行目が列の名前になり、
列の名前の左の印を押すと列の種類を選べます: 文字・数・日付・選択肢(色の札)・チェック(押すと ✓)・リンク(別の文書)。
中身はどれも文字のままなので、いつでも表に戻せます。結合のある表は、結合を外してよいか確かめてから切り替えます。

リンクの列は「題名＋行き先」です。HTML を選ぶかセルへ落とすと、その文書の題名を読んで入れます(読めなければ元の題名のまま)。
別の Monolio の文書を並べると、文書の一覧(ページのデータベース)として使えます。保存した HTML では、押すとその文書へ移ります。
リンクはふつうの表のセルにも付けられます(セルに入って、上のリンクのボタン。データベースのリンクの列と同じ窓が出ます)。
URL(http・https)をセルにそのまま打つか貼ると、その URL へのリンクになります。同じ文書のページも行き先にできます(セルに入って「ページを選ぶ…」で一覧から選ぶ)。エディタでは Ctrl+クリックでそのページへ移り、
ページの題名を変えるとセルの文字もついてきます(自分で変えた文字はそのまま)。ページを消すと、文字を残して行き先だけ外れます。

結合は「表示だけ」で、結合したセルたち（グループ）は**1つの論理値**です。中の各セルは
独立に存在して同じ値を持つので、どのセル番地（A1 でも A2 でも）から参照しても同じ値が
返り、解除しても各セルに値が残って参照は壊れません。範囲参照（`A1:B3` や `A:A`）と
グラフはグループを1回だけ数えます（見た目どおりの集計）。1つの式に同じグループの
**異なる番地**を混ぜる（例: A1:A2 結合で `=A1+A2`）と `#MERGE` エラーになります
（`=A1+A1` のように同じ番地を複数回使うのは合法です）。式の編集中に結合セルを
クリックすると、クリックした位置の番地（左半分なら A1、右半分なら B1）が入ります。
カーソルを表の中へ置くと、表の上に操作ボタンが出ます。セルをドラッグすると範囲を選べます。

列の幅は、セルを選んでいる間に列の右端へ出る縦の帯（セパレータ）で変えられます。
ドラッグでその列だけが広がり・狭まり（隣の列は動きません。Excel と同じ）、
ダブルクリックでその列の最長の内容にぴったり合わせます。帯にフォーカスして
←→キーでも調整できます。幅は文書に保存され、保存HTMLにも同じ幅で焼き込まれます。
本文の欄より広くなった表は、表の中で横にスクロールできます(下にスクロールバーが出ます。保存HTMLも同じ。印刷は紙の幅に縮めて全部刷ります)。

Shift+矢印(セルの端で)や Shift+クリックで範囲を選べます。表の道具の帯で、セルの文字の配置(左・中央・右)と、数の見せ方
(「123」: 桁区切り・パーセント・小数の桁)を選べます。見せ方を変えても中身の数は変わりません。帯の並べ替え(⇅)で今の列の昇順・降順に、
絞り込み(漏斗)で今の列の値を選んで行を隠せます(表の下に「絞り込み中」と出ます。保存HTMLも同じ)。
帯の右端の「全画面」で、表だけを画面の幅いっぱいで編集できます(Esc か「閉じる」で戻ります)。全画面では Excel と同じ行番号・列番号の
見出しが出て、押して列・行を選ぶ(ドラッグ・Shift で複数)、境目で列の幅・行の高さを変える、選んだ列・行を動かす、右クリックで挿入・削除ができます。
行の高さは、ふだんの画面でも行の番号の下の端をドラッグして変えられます(ダブルクリックで中身に合わせる)。
セルの範囲を Ctrl+X で切り取ると点線で囲まれ、同じ表へ Ctrl+V で貼るとセルが式ごと移ります(移したセルを指す式・グラフも移した先を指します。
Excel と同じ。Esc でやめる)。並べ替えでは、式は Excel と同じく行を新しい位置へコピーした扱いになります(上の行を足していく累計は並べ替えた順で計算し直します)。
アクティブなセルの右下の角はフィルハンドルが優先です（Excel と同じ）。

セルに `=` で始まる式を書くと計算します。四則演算と括弧、比べる記号(`= <> < > <= >=`)、文字をつなぐ `&`、文字(`"合格"`)、
`TRUE` `FALSE` と、次の関数が使えます: `SUM` `AVERAGE` `MIN` `MAX` `COUNT` `COUNTA` `ROUND` `ROUNDUP` `ROUNDDOWN` `INT` `ABS`
`IF` `IFERROR` `AND` `OR` `NOT` `COUNTIF` `SUMIF`。

```
=A1+B1*2
=SUM(A1:B10)
=MAX(A1*2, B1*3)
=SUM(A:A)      (A列まるごと。A:C で複数列)
=SUM(2:2)      (2行目まるごと。2:4 で複数行)
=IF(B2>=60, "合格", "不合格")
=COUNTIF(C2:C20, ">=60")
=B2*$E$1       ($ を付けた向きはフィルで動かない。F4 で切り替え)
```

列・行まるごとの参照は「生きた参照」です。書いた時点の表の大きさに固定されず、
計算のたびにいまの表の形で読むので、行や列を増減すると合計も自動で追従します。
式のセル自身が対象の列・行に入っていると、Excel と同じく循環参照（`#CYCLE`）です。
フィルでは列参照は横方向だけ（`A:A`→`B:B`）、行参照は縦方向だけ（`2:2`→`3:3`）動きます。

ヘッダー行・ヘッダー列を宣言した表では、まるごと参照（`A:A` や `2:2`）はヘッダーの
セルを含めません（Excel の構造化テーブルと同じ）。明示的な範囲（`A1:B3`）は宣言に
関係なく全セルを含みます。エラーは `#REF`（参照切れ: 参照先の行・列を削除したなど）、
`#CYCLE`（循環）、`#MERGE`（結合セルの別名混在）、`#ERR`（それ以外）で区別されます。
エラーのセルにマウスを乗せると、式と原因の説明がツールチップで見えます。

セルの編集は **Esc でキャンセル**できます（Excel と同じ）。編集を始めたときの値に
戻り、参照の挿入中でも編集全体が取り消されます。フォーカスはセルに残ります。

式の編集中は Excel と同じポイントモードが使えます。`=` や演算子・`(`・カンマの直後で
別のセルをクリックすると参照（`B2` など）が入り、そのままドラッグすると範囲参照
（`A1:B3` など）になります。ドラッグ中は参照テキストが追従して更新され、対象範囲が
ハイライトされます。続けてクリック／ドラッグすると直前の参照を置き換え、手入力や
セル移動でモードは解除されます。行・列の取っ手（アクティブなセルの列の上・行の左）を
クリックすると、列・行まるごとの参照（`A:A` / `2:2`）が入ります（Excel の列ヘッダ
クリックと同等）。

グラフの定義は matplotlib.pyplot に似せた書き方です。値は表から読み、表を書き換えると
グラフも描き直されます。

```
scatter(A1:A20, B1:B20, label="測定値")
plot(A1:A20, C1:C20, label="近似")
hist(D1:D50, bins=12)
title("測定結果")
xlabel("時間")
ylabel("電圧")
```

散布図と折れ線には近似曲線を引けます(Excel の近似曲線と同じ計算)。種類は直線・二次・対数・指数で、
式と R² もグラフに出せます。

```
scatter(A1:A20, B1:B20, trendline="poly2", trendline_eq=True, trendline_r2=True)
```

グラフは外部ライブラリを使わずSVGを組み立てています（オフラインで動き、単一HTML保存に
そのまま載せられるようにするため）。

## TeX数式

`/math`(/ メニューの「数式」)でブロック数式、本文中の `$$式$$` か `Ctrl+Shift+E`
(ツールバーの √x)でインライン数式を書けます。行頭の `$$式$$` もインライン数式です
(空の段落で `$$` と打ってもブロックには変換されません)。

インライン数式とインラインコードは Obsidian のライブプレビュー型です: 中身はあくまで
`$$式$$` / `` `code` `` という普通の文字列で、キャレットが触れていない間だけ描画結果
(MathML / コード風の見た目)に見せ替わります。矢印キーやクリックでキャレットが範囲に
入ると素のテキストに戻り、普通の文字とまったく同じように編集できます。外へ出ると
再び描画されます。

```
\frac{a+b}{2}   \sqrt[3]{x}   x_i^2   \sum_{i=1}^{n} i^2   \int_0^1 x\,dx
\alpha \beta \Omega   \sin \cos \log \lim   \leq \neq \approx \infty \to
\left( \frac{a}{b} \right)   \begin{pmatrix} a & b \\ c & d \end{pmatrix}   \text{文字}
\underbrace{a+b}_{\text{和}}   \overbrace{x+y}^{n}
a+b \\ c+d   (\\ か \newline で改行して複数行の数式にできます)
```

ソース中の物理改行(Enter)は見た目の整形用で、描画には影響しません(LaTeX と同じ)。
数式の行は `\\` / `\newline` の数で決まります。

描画は外部ライブラリなしで、上記サブセットの TeX を自前で MathML に変換し、ブラウザの
ネイティブ描画に任せます。変換できない書き方はソースがそのまま(赤色で)表示され、
データとしては常に TeX ソースが保持されます。保存HTMLには MathML を焼き込むので、
閲覧側にランタイムは不要です。

既知の制限: MathML の字形は OS の数学フォント(Cambria Math 等)に依存します。

## 提案(人・AI からの変更の案)

本文を書き換えずに「こう変えたら」を文書に入れておき、開いた人が決める仕組みです。AI にファイルを渡して直してもらうときにも使えます。
保存したファイルの先頭の注釈に、AI 向けの案内([docs/format/index.md](./format/index.md)。公開先 `https://woodencaliper.github.io/Monolio/format/`)への
リンクが入っています。ネットにつながる AI なら、ファイルを渡すだけで書き方が分かります。

- 提案があると、本文に差分(消える所は赤の取り消し線、増える所は緑)が重なり、右に提案の一覧が出ます(上の帯の「提案 N」で開閉)。
- 一覧は「提案 → ブロック・表 → 列 → 1か所」の木です。どの段でもチェックで選んで「選んだ所を採用」「選んだ所を戻す」。
- 本文の上でも、語句・セル・ブロックにマウスを乗せると「採用 / 戻す」が出ます。表は範囲を選ぶと、その範囲の提案だけを決められます。
- 決めた結果は文書に残ります(提案した側が、何が採られたかを読めます)。決めるのは Ctrl+Z で戻せます。
- AI・道具から提案を足すには、保存HTMLの先頭の JSON(`#document-manifest`)の `suggestions` に足します。形は先頭の注釈に書いてあります。
- Monolio で開いているファイルを、AI などが外で書き換えると(提案を足す・本文を直接書き換える)、窓に戻ったときにその差分が提案として出ます。
  本文の書き換えは採用するまで入らず、採用しなかった書き換えは保存すると元に戻ります(「ファイル → 開く」で開いた・保存した文書が対象)。

```json
"suggestions": [{
  "author": { "name": "Claude", "kind": "ai" },
  "title": "単位の書き方をそろえる",
  "reason": "「12.0 V」の形にそろえました。",
  "changes": [
    { "op": "setCell", "block": "表のブロックの id", "row": 1, "col": 1, "text": "12.0 V" },
    { "op": "setText", "block": "段落の id", "text": "書き換えた後の文" },
    { "op": "insertBlock", "after": "このブロックの後に", "item": { "type": "paragraph", "text": "足す段落" } },
    { "op": "deleteBlock", "block": "消すブロックの id" }
  ]
}]
```

## 文書チェック

- File メニューの「文書をチェック…」(コマンドパレットでは「チェック」)で、右に結果のパネルが出ます。全ページ(見ていないページ・閉じたトグルの中も)を調べます。
- 調べるもの: 行き先の無い参照・リンク(消した表・図・見出し・ページ・ブロックへの印、ページへのリンク、表のリンクのセル。ゴミ箱にあるときはそう書きます)、
  表の式のエラー(#REF・#CYCLE・#MERGE・#ERR。原因の手掛かりつき)、グラフの定義・データの誤り、図(Mermaid)の文法の誤り(前に描けた図が残っていても、
  いまのコードが誤りなら出ます)、数式(ブロック・文中)の変換の失敗、文書に無い添付を指すブロック。
- 結果は「見つかった問題はありません」「問題が N 件あります」「確かめられなかった項目があります」(図を描けなかった・時間内に描けなかった)の3つ。
  「問題なし」は、上の項目に誤りが見つからなかったというだけで、内容の正しさの保証ではありません。
- 項目を押すと、その場所へ移って光ります(別のページなら切り替え、閉じたトグルは開きます。表のセルはそのセルが光ります)。
- 直したあとはパネルに「チェックのあとで文書が変わりました」と出ます。「再チェック」で結果を新しくします。
- 調べないもの: 外部のリンク(URL)の行き先(文書を外へ送りません)、ゴミ箱のページ、書いた内容・計算の正しさ。結果は文書に保存しません。問題があっても保存・配布はできます。

## 本文の幅

本文の欄の幅は、表示メニューの「本文の幅…」で変えられます(標準は 920px。600px から画面いっぱいまで)。小さな窓のスライダーで変え、
「標準に戻す」「画面いっぱい」のボタンもあります。幅はこのアプリの好みとして覚え、どの文書にも効きます(文書には保存しないので、
保存した HTML の見え方は変わりません)。

## 動画の添付

動画のファイル(mp4・webm など)を添付すると、文書の中でその場で再生できます。保存した HTML をブラウザで開いても再生できます。

- 大きさは、動画にマウスを乗せると左右に出るバーをドラッグして変えます(画像と同じ)。
- 名前・大きさ・Download は、ブロックを選ぶと動画の下に出ます。プレーヤーのメニューからも保存できます。
- 名前と Download だけのカードにしたいときは、つまみのメニューの「ファイルとして表示」(画像も同じ)。「動画として表示」で戻せます。
- 再生できる形式はブラウザで決まります(Chrome・Edge では mp4(H.264・AV1)と webm)。再生できない動画(H.265 の mp4、mov など)は、
  「この環境では再生できませんでした」と出して、ファイルのカードになります(Download で保存して、ほかのアプリで開けます)。
- 動画も文書のファイルの中に入るので、文書がその分(約1.3倍)大きくなります。

## PDF の添付

PDF を添付すると、ダウンロードせずに文書の中で見られます。保存した HTML をブラウザで開いても同じです。

- 最初は1ページ目の見本(小さな絵)です。押すと画面いっぱいに開いて読めます(× か Esc で閉じる)。
- つまみのメニューで「中で読む」(枠の中でページをスクロール)と「ファイルとして表示」(名前と Download だけ)に切り替えられます。
- 「中で読む」の高さは、表と同じく下の端のつまみをドラッグして変えます(ダブルクリックで元の高さ)。
- 大きさは、マウスを乗せると出る左右のバーで変えます(画像・動画と同じ)。
- PDF をその場に出せない環境(スマートフォンのブラウザなど)では、「この環境では PDF をその場で表示できません」と出て、ファイルのカードになります。

## 印刷・PDF

File の「Print / PDF」か `Ctrl+P` で印刷します。PDF は、印刷の画面で「PDF に保存」を選んで作ります。
刷られるのはエディタの画面ではなく、**保存HTMLと同じ形の文書**です(全ページ。ページごとに改ページ)。

- 色・箇条書きの点・表の見出しの地色は、「背景のグラフィック」の設定によらず刷られます
- 紙では開けないので、閉じたトグルも開いて刷ります。グラフのコードは刷りません
- 表がページをまたぐと、次のページの先頭にも見出しの行が出ます(表の見出しの行を設定したとき)
- 保存HTMLをブラウザで開いて印刷しても、同じ形になります
